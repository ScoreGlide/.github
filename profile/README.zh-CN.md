# ScoreGlide · 谱迹

**让乐谱与演奏一起向前。**

ScoreGlide 将乐谱与演奏录音对齐，制作光点跟随音符移动的跟谱视频。我们也在探索基于乐谱和录音证据的音乐讲解与练习建议。

[观看演示](https://demo.scoreglide.com/?lang=zh) · [阅读英文版](README.md) · [联系我们](mailto:hello@scoreglide.com)

## 我们在做什么

- **跟谱视频：**让观众同时看见谱面、听见演奏。
- **音乐理解：**了解乐曲结构、演奏细节和练习思路。
- **审慎分析：**呈现识别与对齐中的不确定性，避免把技术猜测当成演奏错误。

## 当前状态

ScoreGlide 正在内测。公开演示包含精选的视频预览，以及事先准备的音乐分析示例。
